# 零号工厂原创素材目录

这里存放《零号工厂逃生》的独立美术素材，避免和其他固定游戏互相覆盖。

- `zero-factory-background.png`：三关共用的原创工厂背景。
- `maintenance-robot-hero.png`：玩家操作的黄色维修机器人，透明背景。
- `security-robot-enemy.png`：工厂巡逻机器人，透明背景。
- `hero-idle-3f.png`：主角站立呼吸动画，共三帧。
- `hero-run-3f.png`：主角跑步动画，共三帧。
- `hero-jump-3f.png`：主角起跳、腾空和落地动画，共三帧。
- `enemy-patrol-3f.png`：巡逻机器人行走动画，共三帧。
- `enemy-alert-3f.png`：巡逻机器人发现玩家后的警戒动画，共三帧。

门卡、安全门、地面开关和激光门属于会改变状态的机关，游戏中使用程序绘制，不保存为固定图片。
