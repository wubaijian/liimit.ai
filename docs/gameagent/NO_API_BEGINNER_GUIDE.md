# liimit.ai 不接 API 小白完整体验手册

**适用版本**：当前 liimit.ai 源码测试版  
**手册日期**：2026-08-26  
**适合人群**：第一次使用、不懂代码、不配置任何 AI API 的产品经理和测试用户  
**预计体验时间**：30～60 分钟

---

## 先用一句话理解它

不接 API 时，liimit.ai 会送给你一个已经能够运行的 Phaser 3 横版跳跃游戏。你可以拖动关卡、增加和删除物体、亲自试玩、让固定规则机器人自动试玩，并采用系统给出的安全修改建议。

这次体验中：

- 不需要填写 API Key。
- 不会调用或收费使用任何大模型。
- 不要点击“启动 Agent”。
- “主题与关卡创意”会保存在项目中，但不会自动把固定模板变成你描述的独特游戏。
- 自动试玩机器人不是大模型，它只是平台内置的固定规则程序，所以不产生 AI 费用。

## 你这次要体验什么

完成本手册后，你应该亲自体验到：

- 创建一个真实游戏项目。
- 看懂自动准备的几个阶段。
- 拖动关卡物体并自动保存。
- 新增、复制、缩放、删除和撤销关卡物体。
- 在应用内浏览器控制角色移动和跳跃。
- 启动和停止自动试玩。
- 查看自动试玩记录与判断。
- 制造一个容易死亡的位置，让系统提出具体修改建议。
- 由你确认是否采用建议。
- 查看修改前和修改后的自动复测结果。
- 查看项目文件和打开项目保存目录。
- 知道失败时如何点击“重试准备”。

## 第一部分：开始前准备

### 1. 电脑需要具备什么

当前版本还不是公开下载的正式安装版。第一次体验建议使用当前这台开发电脑，并确认：

- 已安装 Node.js 20 或更高版本。
- 已安装 npm。
- 第一次创建项目时电脑可以联网，因为系统可能需要下载固定的游戏运行文件。
- 磁盘至少预留 1 GB 空间。

如果你不确定这些是什么，不要自行安装或修改系统。直接告诉开发人员：“请帮我把 liimit.ai 测试版打开。”

### 2. 准备一个专用保存文件夹

建议在桌面新建一个空文件夹，例如：

```text
liimit体验项目
```

不要选择存放重要照片、合同或其他项目资料的文件夹。liimit.ai 会在你选择的位置下面，再创建一个独立的游戏项目目录。

### 3. 不需要配置 API

本次测试不要进入“设置”填写模型信息。即使所有 API 配置都是空的，基础游戏创建、关卡编辑、人工试玩、自动试玩和规则建议仍然可以使用。

## 第二部分：打开 liimit.ai

### 方法 A：软件已经打开

如果你已经看到左侧写着 `liimit.ai` 的窗口，直接进入下一部分。

### 方法 B：从源码打开

如果软件没有打开：

1. 打开 Mac 的“终端”应用。
2. 复制下面第一行，粘贴到终端，按回车：

```bash
cd "/Users/prom2/Desktop/项目/游戏平台/liimit.ai"
```

3. 再复制下面一行，粘贴并按回车：

```bash
npm run desktop
```

4. 等待 liimit.ai 窗口出现。
5. 体验期间不要关闭终端窗口。关闭终端会同时关闭这个测试版软件。

如果终端提示缺少文件或无法启动，把完整错误截图发回来，不要随意继续输入其他命令。

### 你应该看到什么

第一次打开且没有项目时，主页面会出现：

- “一句话，做出可玩的横版平台游戏”。
- “创建第一个游戏”按钮。
- 左侧“新建游戏”按钮。
- Phaser 3、2D、横版平台跳跃、Web、固定模板等说明。

顶部如果显示 Runtime 已连接，说明桌面程序已经正常启动。它不代表已经连接 AI API。

## 第三部分：创建第一个游戏

### 第 1 步：打开创建窗口

点击首页的“创建第一个游戏”，或者点击左侧“新建游戏”。

你会看到“把一句想法变成游戏”的窗口。

### 第 2 步：填写三个内容

建议本次完全照着填写：

**项目名称**

```text
我的第一个横版游戏
```

**保存位置**

点击“选择”，选择前面准备的“liimit体验项目”空文件夹。

**主题与关卡创意**

```text
一个适合第一次体验的横版平台跳跃游戏，包含金币、尖刺和终点。
```

这里的文字目前只会作为项目想法保存。因为本次不接 API，固定模板不会根据这句话自动生成独特角色、剧情或美术。

### 第 3 步：提交创建

点击“创建制作任务”。

系统会立即创建项目记录，然后在后台自动准备基础游戏。不要点击“启动 Agent”，也不要关闭软件。

### 第 4 步：看懂准备过程

右侧会显示“正在准备基础游戏”，可能依次看到：

1. 等待开始。
2. 复制固定模板。
3. 准备运行环境。
4. 构建 Web 游戏。
5. 检查真实关卡。
6. 检查 Web 试玩。
7. 准备完成。

第一次可能需要几十秒到几分钟，主要取决于网络速度。

### 什么才算成功

准备完成后，右侧会自动开放三个页面：

- “关卡”。
- “Web 试玩”。
- “文件”。

如果左侧项目状态仍写着“待启动”，不要误会。这里的“待启动”主要指可选的 AI Agent 还没有启动，不代表基础游戏不能使用。

### 如果准备失败

如果页面显示“基础游戏准备没有完成”：

1. 先阅读页面给出的中文原因。
2. 确认网络、磁盘空间和保存目录仍然正常。
3. 不要删除项目，也不用重新填写创建表单。
4. 点击唯一的“重试准备”。
5. 等待它重新检查。

失败时已经安全写入的项目资料仍然会保留。

## 第四部分：认识整个工作台

选择项目后，界面可以简单理解成三块：

### 左边：项目列表

这里用于：

- 新建游戏。
- 切换不同项目。
- 查看项目大致状态。
- 打开设置。

本次不需要进入设置配置 API。

### 中间：制作与 AI 区域

这里主要显示制作阶段、运行记录和可选的 Agent 输入框。

不接 API 时：

- 可以查看项目状态。
- 不要点击“启动 Agent”。
- 不要在底部输入框提交修改要求。

页面显示“AI 是可选步骤；启动后 AI 可能修改当前项目文件”，就是在提醒你：AI 与基础游戏体验是两件事。

### 右边：当前最重要的体验区

右侧有三个标签：

- “关卡”：拖动和调整关卡。
- “Web 试玩”：亲自玩、自动试玩、查看建议和复测。
- “文件”：查看这个游戏真实包含哪些文件。

## 第五部分：完整体验可视化关卡编辑

点击右侧“关卡”。你会看到一张可以横向滚动的关卡图。

### 先认识关卡物体

根据页面图例辨认：

- 出生点：玩家开始的位置。
- 平台：角色可以站立的地面或落脚点。
- 尖刺：角色碰到后死亡。
- 金币：角色可以收集。
- 终点：角色到达后完成关卡。

### 体验 1：拖动物体

1. 在画布里找到一枚金币。
2. 用鼠标按住金币。
3. 向右拖动一小段距离。
4. 松开鼠标。
5. 等待顶部提示从“正在保存新位置……”变为“新位置已保存”。

这里不需要再点击“保存”。松开鼠标后系统会自动保存。

### 体验 2：撤销刚才的移动

1. 点击顶部“撤销”。
2. 确认金币回到移动前的位置。
3. 确认提示说明撤销已经保存。

注意：目前只能撤销当前页面最近一次成功编辑，不支持连续多步撤销，也不支持重做。

### 体验 3：新增平台

1. 点击“新增平台”。
2. 等待“平台……已新增并保存”。
3. 在关卡图中找到新平台。
4. 把它拖到一个容易看见的位置。

### 体验 4：调整平台大小

1. 点击刚才新增的平台，让它进入选中状态。
2. 点击“加宽”，观察平台变长。
3. 点击“缩短”，观察平台变短。
4. 点击“变高”，观察平台变厚。
5. 点击“变矮”，观察平台变薄。

按钮变灰通常代表：还没有选中正确物体、当前正在保存，或者继续调整会让关卡数据无效。

### 体验 5：新增金币和尖刺

1. 点击“新增金币”。
2. 点击“新增尖刺”。
3. 等待两次保存完成。
4. 分别在画布中找到新增物体。
5. 尝试拖动它们。

### 体验 6：放大和缩小

1. 点击金币或尖刺。
2. 点击“放大”。
3. 点击“缩小”。

“放大/缩小”用于金币和尖刺；“加宽/缩短/变高/变矮”用于平台。

### 体验 7：复制物体

1. 选中普通平台、金币或尖刺。
2. 点击“复制”。
3. 系统会生成一份新的物体并自动保存。
4. 把复制出来的物体拖到其他位置。

### 体验 8：删除物体

1. 选中刚才复制或新增的物体。
2. 点击“删除”。
3. 等待删除保存完成。

如果“删除”按钮不可用，说明当前物体受到保护，或者还没有正确选中物体。不要尝试删除出生点、基础地面或终点来完成这项测试，优先删除自己新增的物体。

### 编辑功能完成标准

你应该已经看到过这些成功提示中的大部分：

- 新位置已保存。
- 平台已新增并保存。
- 金币已新增并保存。
- 尖刺已新增并保存。
- 物体已复制并保存。
- 物体已删除并保存。
- 平台大小已经修改并保存。

## 第六部分：人工试玩游戏

### 第 1 步：打开 Web 试玩

1. 点击右侧“Web 试玩”。
2. 点击“载入 Web 试玩”。
3. 等待游戏画面出现。

如果按钮显示“正在连接”，继续等待，不要快速重复点击。

### 第 2 步：让游戏接收键盘

先用鼠标在游戏画面中点击一下，然后使用键盘。

### 第 3 步：体验角色操作

- 右方向键或 `D`：向右移动。
- 左方向键或 `A`：向左移动。
- 上方向键、`W` 或空格：跳跃。

请至少完成：

1. 向右移动。
2. 向左移动。
3. 跳跃一次。
4. 尝试收集金币。
5. 尝试碰到尖刺，观察角色是否重新开始。
6. 尝试向终点前进。

### 第 4 步：观察试玩记录

游戏下方“试玩记录与自动控制”会显示：

- 尝试次数。
- 使用时间。
- 最远位置。
- 最后位置。
- 跳跃次数。
- 收集金币数量。
- 死亡次数。
- 最后碰到的尖刺。

如果你刚才修改了关卡但试玩里没有变化，点击试玩顶部的刷新按钮，让游戏重新读取最新版关卡。

## 第七部分：体验自动试玩

### 正常启动

1. 确认 Web 游戏已经载入，并且试玩状态不再是“等待游戏开始”。
2. 点击“开始自动试玩”。
3. 观察“机器人”状态。

你可能看到：

- 向右移动。
- 向左移动。
- 跳跃。
- 等待。

机器人会尝试向终点前进，并判断前方是否需要跳跃。

### 查看结果

自动试玩可能得到：

- 成功：机器人到达终点。
- 重复死亡：在同一危险附近死亡多次。
- 卡住：连续一段时间没有明显前进。
- 超时：规定时间内没有到达终点。
- 已停止：你在结果出来前点击了“停止”。

### 体验停止按钮

1. 再次点击“开始自动试玩”。
2. 在机器人仍然运行时点击“停止”。
3. 确认判断显示为你主动停止，而不是成功或失败。

## 第八部分：故意制造问题，体验修改建议和自动复测

这一部分用于体验“系统发现问题 → 告诉你改哪里 → 由你确认 → 自动复测”。它仍然不使用 AI API。

### 第 1 步：在出生点附近放置尖刺

1. 回到“关卡”。
2. 点击“新增尖刺”。
3. 找到新增的红色尖刺。
4. 把它拖到出生点前方、角色很容易碰到的位置。
5. 等待“新位置已保存”。

不要覆盖出生点本身，放在角色向右移动时很快会遇到的位置即可。

### 第 2 步：重新载入游戏

1. 回到“Web 试玩”。
2. 点击试玩顶部的刷新按钮。
3. 等待新游戏开始。

### 第 3 步：让机器人反复测试

1. 点击“开始自动试玩”。
2. 等待机器人多次碰到新增尖刺。
3. 最长等待约 30 秒。

理想结果是出现“重复死亡”。如果机器人成功跳过去，可以回到关卡把尖刺再向出生点靠近一点，或者再增加一个尖刺，然后刷新并重新测试。

### 第 4 步：阅读具体修改建议

出现失败判断后，页面会显示“具体修改建议”。认真查看：

- 修改目标。
- 当前值。
- 建议值。
- 为什么建议这样改。
- 可能造成什么影响。

页面会明确写着“仅建议，尚未修改关卡”。这说明系统不会在你不知道的情况下偷偷修改。

### 第 5 步：由你确认修改

1. 点击“采用这个建议”。
2. 阅读二次确认。
3. 点击“确认修改”。

如果建议针对反复死亡的尖刺，当前规则一般会建议删除导致反复死亡的那根尖刺。

### 第 6 步：查看自动复测

确认后，系统会：

1. 保存最新版关卡。
2. 重新载入游戏。
3. 自动启动一次机器人试玩。
4. 显示修改前和修改后的对比。

对比结果可能是：

- 有改善。
- 变差。
- 暂无明确变化。
- 无法判断。

系统本轮只修改一次、复测一次，不会根据结果无限循环修改。

## 第九部分：查看真实项目文件

### 在应用里查看

1. 点击右侧“文件”。
2. 浏览项目目录结构。
3. 找到 `src/level.json`，它就是关卡编辑器保存的真实关卡数据。
4. 找到 `dist/index.html`，它是浏览器试玩版本的入口之一。

除非开发人员指导，不要直接修改这些文件。

### 在 Finder 中查看

点击窗口顶部的文件夹图标“打开项目目录”。系统会在 Finder 中打开当前游戏项目。

你应该能确认：这个游戏真实保存在你选择的电脑目录中，不只存在于 liimit.ai 页面里。

## 常见问题

### 1. 为什么我写了游戏创意，游戏还是固定样子？

因为本次没有接 API。系统只会创建固定的横版游戏模板，创意文字会保存下来，但不会由大模型理解和执行。

### 2. 为什么项目显示“待启动”，但右边已经可以玩？

“待启动”主要表示可选的 AI Agent 没有启动。只要“关卡”和“Web 试玩”已经开放，基础游戏就是可用的。

### 3. 为什么“开始自动试玩”按钮是灰色的？

先点击“载入 Web 试玩”，等待游戏真实启动。页面收到游戏开始消息后，按钮才会开放。

### 4. 为什么修改关卡后，试玩没有变化？

点击 Web 试玩顶部的刷新按钮。游戏会重新读取已经保存的最新版关卡。

### 5. 为什么某些编辑按钮是灰色的？

通常是因为没有选中正确类型的物体。例如：

- 平台才能使用加宽、缩短、变高、变矮。
- 金币和尖刺才能使用放大、缩小。
- 受保护物体不能删除或复制。
- 系统正在保存时，编辑按钮会暂时禁用。

### 6. 为什么自动试玩没有提出建议？

只有机器人得到“重复死亡”“卡住”或“超时”等失败结论后，才会给出安全建议。成功通关时没有必要修改。

### 7. 为什么第一次创建比较慢？

第一次可能需要下载约一百多个固定运行文件。之后相同环境通常可以跳过重复安装。

### 8. 可以直接关闭软件吗？

可以。已经成功保存的关卡和项目文件会留在你选择的目录中。正在准备时关闭，下次打开会显示上次中断并允许重试。
