# 契约：单一模式 UI 表面

## 首页

必须明确展示以下四个边界：

1. Phaser 3 · 2D；
2. 横版平台跳跃；
3. Web 浏览器试玩；
4. 固定 platformer 模板。

不得继续展示“五种游戏架构”“自动选择模板”或其它引擎能力。

## 新建弹窗

- 只有项目名称、保存位置和主题/关卡创意三类用户输入。
- 固定模式信息在确认创建前可见，但不是选择控件。
- 示例只能描述横版平台玩法的主题、关卡和机制变化。
- 不出现 engine、archetype、dimension 或 preview target 选择器。

## 制作与试玩

- 保留内部 `classify` stage ID，避免旧项目和事件不兼容；用户标签改为“平台模板”等固定语义。
- 预览区域明确称为“应用内 Web 浏览器试玩/预览”，继续使用现有 sandbox iframe，不暗示或启动系统 Chrome/Safari。
- 缺少 `dist/index.html` 时提示先完成构建，不展示外部引擎替代方案。

## 暂时隐藏的入口

- 主导航不展示插件入口。
- 设置保留“运行环境 / Node.js 与构建工具”入口，用于检测和恢复 Node.js/npm；不展示 Unity、Godot、Blender 等外部游戏引擎及与固定模式无关的工具。
- 对应实现和本地数据仍保留，旧项目与后续迁移可以继续读取。
- 本步骤不把可视化编辑器或 AI 自动试玩描述为已交付能力。
