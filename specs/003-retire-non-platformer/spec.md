# 功能规格：退役非横版项目与模板

**功能编号**：003
**状态**：已确认
**确认日期**：2026-08-23

本规格取代 `002-platformer-only-mode` 中关于保留旧项目、五分类兼容路径和非横版模板的要求；002 继续作为上一阶段的历史实施记录。

## 用户目标

liimit.ai 只制作 Phaser 3 的 2D 横版平台跳跃游戏。升级后，平台不再显示、打开、续跑或生成缺少固定产品标记的旧项目，也不再携带俯视、网格、塔防和 UI 驱动四类模板。

## 用户故事与验收

### US1：项目列表只出现横版项目（P1）

用户启动新版 liimit.ai 后，只能看到 `productMode: phaser-platformer-web` 的项目。旧记录从活动项目列表移除，但应用不得自动删除用户项目目录、设置或凭据。

**验收场景**：给定一个横版项目、一个缺少标记的旧项目和一个未知标记项目，启动后只返回横版项目；落盘前保存原始状态备份，项目目录均保持不变。

### US2：运行链路只能进入固定横版模式（P1）

任何项目创建、更新、运行、预览和文件操作都只能使用固定产品模式。Renderer 不得提交或切换产品模式。

**验收场景**：Main 创建的项目始终带固定标记；StateStore 拒绝写入非固定项目；Runtime 始终注入 `platformer`，且不加载用户 Skills/MCP。

### US3：安装包只携带横版模板（P1）

游戏类型工具不再调用模型选择玩法，而是确定性加载 platformer 模板。发布资源中不存在 `top_down`、`grid_logic`、`tower_defense`、`ui_heavy` 模板与模块文档。

**验收场景**：即使用户要求塔防或俯视游戏，工具也返回 platformer 并只复制横版模板；四个退役目录不存在；GDD 只接受 `platformer`。

## 功能要求

- **FR-001**：`ProjectRecord.productMode` 必须是必填的固定产品模式类型。
- **FR-002**：旧/未知项目记录必须在启动迁移中从活动 `projects` 数组移除。
- **FR-003**：迁移删除记录前必须保存原始 `state.json` 的可恢复备份；备份失败时不得覆盖原状态。
- **FR-004**：迁移不得删除项目目录、Provider 设置、凭据、MCP 配置或未知扩展字段。
- **FR-005**：StateStore 必须拒绝写入非固定模式项目。
- **FR-006**：Agent Runtime 必须无条件采用固定 platformer 策略，不得存在旧项目 Skills/MCP 分支。
- **FR-007**：制作流水线只保留固定横版文案，不得根据项目标记切换为通用分类文案。
- **FR-008**：`classify_game_type` 必须确定性返回 platformer，不发起分类模型请求。
- **FR-009**：脚手架 API 必须在运行时拒绝 platformer 之外的 archetype，即使调用方绕过 TypeScript。
- **FR-010**：`generate_gdd` 的类型、Schema 与运行时校验只能接受 platformer。
- **FR-011**：删除四类非横版模板目录、对应模块文档及未被产品调用的多 archetype 模板演化原型，并清理已发布 Prompt/通用文档中的支持声明。
- **FR-012**：不得删除与项目类型无关的历史事件格式、Provider 兼容、IPC 身份或安全存储兼容代码。
- **FR-013**：`generate_tilemap` 必须只公开横版平台地图契约，移除旧的多 tileset 模式，并在写文件前拒绝旧调用参数。

## 边界情况

- 旧状态同时包含固定与非固定项目时，只迁移非固定记录。
- 迁移备份或新状态写入失败时，应用初始化失败，原状态保持可恢复。
- 已经缺失 `projects` 字段的早期状态按空数组处理，不需要生成迁移备份。
- 用户项目目录即使位于默认工作区，也不能由启动迁移自动删除。

## 成功标准

- **SC-001**：混合状态迁移测试中，活动项目 100% 为固定模式，设置、凭据、MCP 和未知键语义不变。
- **SC-002**：桌面端项目模式、StateStore、ProjectManager 与 AgentRunner 聚焦测试全部通过。
- **SC-003**：Core 分类器、GDD 和 Tilemap 测试证明只存在 platformer 契约，且分类过程网络调用次数为 0。
- **SC-004**：四个退役模板目录、四个退役模块文档目录及独立多 archetype 模板演化原型均不存在。
- **SC-005**：Desktop 与 Core 类型检查、测试、构建以及 `git diff --check` 通过。

## 明确不做

- 不删除用户磁盘上的游戏项目目录。
- 不清空 liimit.ai 设置、凭据、缓存或应用身份。
- 不处理第二阶段的可视化拖拽编辑器。
- 不处理第三阶段的 AI 自动试玩与修改建议。
