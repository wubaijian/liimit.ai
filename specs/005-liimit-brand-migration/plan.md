# 实施计划：liimit.ai 品牌迁移

## 宪章检查

- 品牌事实与用户目标一致：将宪章中的强制品牌同步修订为 `liimit.ai`。
- 兼容性：保留 Electron `appId=com.gameagent.desktop`，不借品牌更名改动凭据和安装器身份。
- 证据先于交付：全仓搜索、契约测试、类型检查、Lint、黄金路径和实际打包都纳入验收。

## 实施顺序

1. 先修订项目宪章、AGENTS 说明和品牌规格，确立唯一名称。
2. 更新 Desktop manifest、主进程、Renderer、默认目录和用户错误文案。
3. 成对更名内部命令、环境变量、冒烟标识、临时目录及其测试。
4. 更新 Windows/macOS 产物名、工作流、验证脚本和品牌契约。
5. 更新 README、用户文档、历史规格和包元数据，移除误导性上游发布链接。
6. 重命三张无文字品牌图片文件，更新引用。
7. 执行全仓残留搜索、测试、构建和打包，确认产物名为 `liimit.ai`。

## 风险与控制

- **假仓库地址**：不把上游组织名与新品牌拼成不存在的 URL；移除受控包中的上游地址，等用户提供新地址。
- **凭据或记录失效**：不改 `appId`，不改存储格式；启动时仅迁移应用状态、Agent 历史和 API 用量，目标已存在时不覆盖。
- **Skill 元数据断层**：新版写入新文件名，同时兼容读取旧文件名。
- **脚本半更名**：每个标识与消费方在同一变更中成对修改，由契约测试覆盖。
- **历史资料误导**：历史 Spec 保留功能事实，但品牌名与当前项目一致。
