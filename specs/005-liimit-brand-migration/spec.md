# 功能规格：liimit.ai 品牌迁移

**功能编号**：005
**状态**：已完成
**创建日期**：2026-08-24

## 用户目标

项目所有对外品牌都使用 `liimit.ai`，不再把原项目名称、上游下载地址或上游维护方误当成当前项目身份。

## 用户故事与验收

### US1：客户端品牌一致（P1）

用户在 macOS、Windows、窗口、菜单、快捷方式、默认项目目录和帮助文档中只看到 `liimit.ai`。

**验收场景**：品牌契约测试同时校验 Desktop manifest、主进程、Renderer、安装包文件名和用户文档；受控源码中不再存在旧品牌文字。

### US2：构建与内部识别一致（P1）

开发者运行测试、黄金路径、Windows 发行工作流和打包验证时，环境变量、冒烟标识、临时目录和产物名称都使用 `LIIMIT` / `liimit`前缀。

**验收场景**：聚焦契约测试、全仓搜索、Desktop 类型检查和打包通过。

### US3：品牌更名不破坏安全身份（P1）

已有客户端用户的安全存储、安装升级身份和本地项目数据不应仅因显示品牌变化而失效。

**验收场景**：保留 `appId=com.gameagent.desktop`；旧用户数据中的应用状态、Agent 历史和 API 用量记录可迁移；旧版 Skill 来源元数据可继续读取。

## 功能要求

- **FR-001**：所有用户可见品牌必须精确使用 `liimit.ai`。
- **FR-002**：安装包、DMG、Windows EXE、Artifact 和默认项目目录必须使用新品牌。
- **FR-003**：内部环境变量、命令参数、冒烟标识和临时资源必须使用 `LIIMIT` / `liimit`前缀。
- **FR-004**：文档不得继续展示上游仓库的历史下载为当前产品下载。
- **FR-005**：Electron `appId` 保持不变，避免破坏安装器升级和安全存储身份。
- **FR-006**：品牌图片资产文件名改为 `liimit-ai-*`；图片内没有文字时保留已有视觉内容。
- **FR-007**：必须更新项目宪章、开发说明、历史规格中的品牌事实和品牌契约测试。
- **FR-008**：更名后必须安全迁移应用自身的本地数据，遇到目标冲突时不覆盖，不移动用户的游戏项目目录。
- **FR-009**：旧版 Skill 来源元数据必须兼容读取，新安装只写入新品牌文件。

## 成功标准

- **SC-001**：排除 `.git`、依赖和生成产物后，受控源码不再匹配旧品牌及其大小写内部前缀。
- **SC-002**：Desktop 品牌、Windows 打包和 Runtime 冒烟契约测试通过。
- **SC-003**：全仓类型检查、Desktop 全量测试、Lint、黄金路径和当前平台 App 打包通过。
