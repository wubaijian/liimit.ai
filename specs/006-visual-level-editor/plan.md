# 实施计划：可视化关卡编辑器

## 宪章检查

- 仍然只支持 Phaser 3、2D 横版平台跳跃和 Web 试玩。
- 关卡文件由主进程安全读写，网页界面不直接访问文件系统。
- 保存时需要检查项目路径和数据结构，并使用不会留下半个文件的替换方式。
- 每个小步验证后暂停，等待用户确认。

## 分步顺序

1. 关卡数据基础：定义关卡和五种物体的统一格式，提供默认关卡和数据检查。
2. 安全保存与读取：在项目目录内保存关卡文件，失败时不覆盖有效旧文件。
3. 只读画布：先让用户在 liimit.ai 中看到关卡，暂时不允许拖动。
4. 单物体拖动：只实现选中和移动，保存后可恢复。
5. 新增普通平台：先让用户通过一个明确按钮添加固定尺寸的平台。
6. 删除选中物体：保护出生点、终点和最后一个平台，并提供保存失败回退。
7. 复制选中物体：只复制平台、金币和尖刺，并自动错开位置。
8. 改变平台宽度：通过按钮按网格缩短或加宽当前选中的普通平台。
9. 新增金币：通过一个明确按钮新增固定尺寸的金币。
10. 新增尖刺：通过一个明确按钮新增固定尺寸的尖刺。
11. 撤销上一步：保存当前会话最近一次成功编辑的旧关卡，并允许安全恢复。
12. 试玩同步：让固定 Phaser 模板和应用内预览读取同一份关卡数据。
13. 改变平台高度：通过按钮按网格变矮或变高当前选中的普通平台。
14. 改变金币和尖刺大小：通过统一按钮按网格缩小或放大选中的金币或尖刺。
15. 其余尺寸编辑：再分步评估出生点、终点和自由拉伸。

## 当前仅授权的实施范围

第 1 至第 13 步已经完成并获得用户确认。本轮只实施第 14 步：

- 只允许金币和尖刺统一缩小或放大，宽度与高度每次同时改变一个网格。
- 保持物体的左上角位置不变；最小尺寸为一个网格。
- 放大后不能超过关卡右边或底部。
- 调整后只安全保存一次；保存失败恢复调整前的完整关卡。
- 成功调整进入已有的一步撤销记录，撤销后恢复原尺寸和选中状态。
- 本轮不修改平台、出生点和终点，也不实现鼠标自由拉伸、连续撤销或 AI 自动试玩。

## 第 14 步验证

- 缩小和放大只改变选中金币或尖刺的宽高一个网格。
- 最小尺寸、右侧和底部边界、禁止类型和不存在物体都有明确限制。
- 成功时只保存一次并建立撤销记录；失败时恢复原关卡且不覆盖旧撤销记录。
- 原有拖动、新增、删除、复制、平台尺寸、撤销和试玩同步行为保持不变。
- Desktop 全量测试、类型检查和构建通过。
