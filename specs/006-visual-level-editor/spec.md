# 功能规格：可视化关卡编辑器

**功能编号**：006
**状态**：分步实施中
**创建日期**：2026-08-24

## 用户目标

不会写代码的用户也能在 liimit.ai 中看到横版关卡，用鼠标放置和调整关卡物体，保存后在试玩中看到同样的结果。

## 固定产品范围

第一版只编辑 Phaser 3 的 2D 横版平台跳跃关卡，只包含五种物体：

1. 玩家出生点
2. 普通平台
3. 尖刺
4. 金币
5. 终点

敌人、移动平台、机关、剧情、美术素材替换和 AI 自动试玩不属于本阶段。

## 用户故事与验收

### US1：关卡有统一的保存格式（P1）

系统能稳定记录关卡大小和五种物体的位置、大小与唯一编号。损坏、越界或缺少必要物体的数据不得被当成有效关卡。

**验收场景**：默认关卡能通过检查；缺少出生点、缺少终点、编号重复、物体越界和未知物体都会给出清楚错误。

### US2：用户可视化编辑关卡（P1）

用户能在画布中选择、拖动、改变大小、复制和删除关卡物体，并能撤销错误操作。

### US3：编辑结果与试玩一致（P1）

关卡编辑器和 Phaser 试玩必须读取同一份关卡数据。用户保存并重新打开项目后，关卡不能恢复成旧位置。

## 分步交付规则

本功能必须小步交付。每一步完成、测试并向用户报告后，必须停止实施，等待用户明确确认再进入下一步。

## 成功标准

- 用户无需编辑代码就能调整第一版的五种关卡物体。
- 保存失败不会清空已有关卡。
- 编辑器和试玩使用同一份受检查的关卡数据。
- 现有的 AI 制作、构建和 Web 试玩流程不被破坏。
