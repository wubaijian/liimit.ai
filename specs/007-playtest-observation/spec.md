# 功能规格：试玩观察与自动试玩

**功能编号**：007  
**状态**：分步实施中  
**创建日期**：2026-08-24

## 用户目标

用户能够先看到一次试玩中真实发生了什么，再逐步让系统自动操作、判断问题、提出修改建议，并且只在用户确认后修改关卡。

## 固定第一版范围

- 只观察固定 `VisualLevelScene` 中的玩家、金币、尖刺和终点事件。
- 第一阶段只记录人工试玩，不自动操作、不调用模型、不修改关卡。
- 后续自动试玩只针对固定 Phaser 2D 横版模板。
- AI 建议必须指出物体编号和修改前后数值，未经用户确认不得应用。

## 第一阶段验收

Web 试玩加载后，liimit.ai 能安全接收同一试玩 iframe 发出的固定格式事件，并显示：尝试次数、用时、最后位置、最远横向位置、跳跃次数、当前尝试收集的金币、死亡次数、最后碰到的尖刺和通关状态。

刷新试玩、重新检测或切换项目时，旧记录必须清空。其他窗口、其他来源或格式错误的消息不得改变报告。

## 分步交付规则

每完成一项并通过测试后停止，向用户报告并等待确认。
