# UI Contract: 第三版界面预览

## 新建项目分流

1. 默认选择“横版平台跳跃”，明确显示 Phaser 3 与“当前可用”。
2. 横版提交继续使用现有真实创建回调，输入结构保持不变。
3. 选择“俯视角迷宫”后，明确显示 Godot 与“界面预览，尚未接入”。
4. 迷宫提交只把名称与创建方式交给渲染层预览，不调用 `window.gameAgent`。

## 迷宫预览工作台

1. 页面始终显示产品名、Godot/迷宫标识和未接入提示。
2. 关卡、对象和面板交互只更新组件本地状态。
3. AI、试玩、验证和导出面板都必须说明预期流程以及本轮不执行真实操作。
4. 任何“保存、确认、开始、应用、导出”类点击都必须产生可见提示，不得静默伪装成功。
5. 关闭预览立即丢弃全部本地状态并返回现有工作台。

## 禁止的调用

- 不调用任何 `window.gameAgent` 方法。
- 不读取或写入项目文件、设置、凭据或历史记录。
- 不启动 Agent、预览服务器、Godot、构建、自动验证或导出。
- 不新增 Preload、IPC、主进程或持久化契约。
