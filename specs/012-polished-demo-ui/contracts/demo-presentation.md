# UI Contract: 正式化演示界面

## Default presentation

- 首页、新建窗口和迷宫工作台以游戏创作为主语义。
- 不在默认视图反复显示“界面预览”、“尚未接入”、“当前只做 UI”、“界面样稿”或“不会执行真实操作”。
- 每个 Godot 页面最多显示一枚弱化的“演示模式”标识。

## Contextual result feedback

- 当结果型操作并不真正写入数据时，点击后显示：`演示模式：本次操作仅用于体验，不会写入真实项目数据。`
- 可在句尾增加简短操作名称，但不得声称保存、构建、试玩、验证、AI 修改或导出已真实成功。
- 新提示替换旧提示，不创建多个堆叠消息。

## Static result labels

- AI 方案和验证结果可用于展示完整界面。
- 静态结果标题旁显示小型“示例数据”标识。
- 标识不得占据整块面板或打断主操作流。

## No-side-effect boundary

- Godot 迷宫路径不调用 `window.gameAgent`。
- 不新增或修改主进程、Preload、IPC、共享项目类型、持久化结构或 Godot 依赖。
- 返回工作台后，现有 Phaser 项目数量、选中状态和文件不变。
