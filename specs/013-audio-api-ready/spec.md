# Feature Specification: 音效 API 接通与测试

**Feature Branch**: `main`

**Created**: 2026-09-01

**Status**: Draft

**Input**: User description: "让已经填写的 ElevenLabs 音效 API 能被准确检查、可靠保存，并能在不配置图片 API 的情况下生成和试听一个短测试音效；暂时不把音效绑定到正式游戏关卡。"

## User Scenarios & Testing _(mandatory)_

### User Story 1 - 看懂音效 API 是否可用 (Priority: P1)

用户在音频设置中保存 ElevenLabs 密钥后，页面立即显示已配置。用户执行不产生音效、也不消耗生成额度的基础检查时，可以区分“密钥无效”“音效权限不足或 IP 受限”“服务可连接”等不同结果，不会再把所有拒绝都笼统说成密钥无效。

**Why this priority**: 用户目前第一步就被错误的鉴权提示卡住；只有先把配置状态和检查结果说清楚，后面的音效测试才可信。

**Independent Test**: 分别模拟连接成功、密钥无效和权限受限三种结果，确认页面即时更新保存状态，并显示对应的通俗提示，同时没有产生音效或额度消耗。

**Acceptance Scenarios**:

1. **Given** 用户填写完整的音效密钥，**When** 保存设置成功，**Then** 当前音频服务立即显示“已配置”，无需关闭再打开窗口。
2. **Given** ElevenLabs 已识别密钥但拒绝音效能力检查，**When** 返回权限不足或 IP 受限结果，**Then** 页面说明“密钥已被识别，但可能缺少 Sound Effects 权限或受到 IP 限制”，不得直接断言密钥无效。
3. **Given** 服务明确返回密钥无效，**When** 基础检查结束，**Then** 页面提示重新复制或新建密钥。
4. **Given** 用户只执行基础检查，**When** 检查完成，**Then** 不生成音频、不保存文件，也不消耗声音生成额度。

---

### User Story 2 - 只配音效 API 也能生成声音 (Priority: P2)

用户只配置音效服务、不配置图片服务时，音效生成请求可以直接使用音效服务，不会被“缺少图片 API”提前拦住。需要图片的素材请求仍然必须检查图片配置。

**Why this priority**: 目前纯音效请求会被无关的图片配置阻断，这是音效 API 即使有效也无法使用的确定原因。

**Independent Test**: 在只有音效配置的环境中提交一条纯音效请求，确认请求进入音效生成；再提交图片请求，确认图片配置仍按原规则校验。

**Acceptance Scenarios**:

1. **Given** 用户只配置了音效服务，**When** 发起纯音效生成，**Then** 系统不得要求配置图片服务。
2. **Given** 同一环境没有图片服务，**When** 发起图片或包含图片的素材生成，**Then** 系统继续给出明确的图片配置提示。
3. **Given** 一批请求同时包含音效和图片，**When** 处理素材，**Then** 每类素材只检查自己需要的服务，已成功的部分不得被无关配置取消。

---

### User Story 3 - 生成并试听一个测试音效 (Priority: P3)

用户可以在 ElevenLabs 音频设置中主动生成一个很短的固定测试音效。页面在操作前明确说明会消耗少量额度，生成后可以直接播放或重新生成；音频只用于本次设置测试，不会自动加入项目或绑定关卡。

**Why this priority**: 基础检查只能验证连接或账户权限，真正生成一次短声音才能证明“声音生成权限、套餐和返回音频”整条链路可用。

**Independent Test**: 使用有效的 ElevenLabs 音效配置点击一次测试生成，确认出现进度、得到可播放音频，并且项目文件和关卡配置没有变化。

**Acceptance Scenarios**:

1. **Given** 当前选择 ElevenLabs 且已填写密钥，**When** 用户查看测试入口，**Then** 页面明确标注“会消耗少量 ElevenLabs 额度”。
2. **Given** 用户主动点击生成测试音效，**When** 服务返回成功，**Then** 页面提供可直接播放的短音频，并显示本次生成成功。
3. **Given** 声音生成权限、套餐、网络或请求有问题，**When** 测试失败，**Then** 页面显示可行动的错误信息，不得一直停留在加载状态。
4. **Given** 测试音效生成成功，**When** 用户关闭设置窗口或生成新的测试音效，**Then** 旧的临时试听数据被释放，且不写入任何游戏项目。

### Edge Cases

- 用户只输入了密钥但尚未保存时，基础检查可以使用当前输入值；实际测试音效必须先保存设置，确保密钥只由安全存储交给生成服务。
- 用户在生成过程中关闭设置窗口时，返回结果不得触发已卸载页面更新，也不得把音频写入项目。
- 服务返回空音频、超大响应或非音频内容时，系统必须拒绝试听并给出错误。
- 连续点击生成按钮时，只允许一个测试生成进行中，避免重复扣费。
- 受限密钥、IP 白名单、余额不足和频率限制必须使用不同于“密钥无效”的提示。
- 音效测试不得在日志、错误信息或用量记录中保存或展示密钥。

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: 保存音频设置成功后，页面必须立即把当前音频服务标记为已配置。
- **FR-002**: 基础检查必须保持不生成音频、不写项目文件和不消耗声音生成额度。
- **FR-003**: 基础检查必须区分明确无效的密钥、权限或 IP 限制、余额问题、频率限制、网络问题与成功连接。
- **FR-004**: 权限或 IP 限制不得被笼统描述为“API Key 无效”，页面必须引导用户使用实际音效测试进一步确认。
- **FR-005**: 纯音效请求必须能够在未配置图片服务的情况下进入音效生成流程。
- **FR-006**: 图片、视频和混合素材请求必须继续按其实际需要校验对应服务，不得因音效解耦绕过必要配置。
- **FR-007**: ElevenLabs 音频设置必须提供一个用户主动触发的短测试音效入口。
- **FR-008**: 测试入口必须在点击前明确说明可能消耗少量服务额度，并防止进行中重复点击。
- **FR-009**: 成功的测试结果必须可在设置窗口中直接试听，但不得自动写入项目、素材清单或关卡。
- **FR-010**: 测试结果必须限制为预期的音频类型和安全大小；空响应、非音频或超限内容必须被拒绝。
- **FR-011**: 用户关闭设置或开始新测试时，旧的临时试听资源必须被释放。
- **FR-012**: 所有密钥必须继续只通过系统安全存储和受控桌面通道使用，不得进入渲染页面、日志、用量记录或错误文本。
- **FR-013**: 每次基础检查和实际音效测试必须结束于成功、警告或错误状态，不得无限加载，并应记录不含秘密信息的耗时与结果。
- **FR-014**: 本次不得把测试音效绑定到跳跃、金币、死亡、通关等游戏事件，也不得修改现有游戏项目。
- **FR-015**: 实际测试音效必须使用已经保存到系统安全存储的音频密钥；页面不得把密钥作为测试音效请求参数再次传递。

### Key Entities

- **音频配置状态**: 当前音频服务是否已安全保存，以及用户正在编辑但尚未保存的字段。
- **基础检查结果**: 不产生素材的连接检查结果，包含成功、警告或错误、通俗说明和耗时。
- **临时测试音效**: 由用户主动生成、只在当前设置窗口试听的短音频，不属于项目素材。
- **音效测试记录**: 不含密钥和音频正文的结果、耗时、服务商与调用类型记录。

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 保存成功后 1 秒内，音频服务的“已配置”状态在当前窗口中更新。
- **SC-002**: 对连接成功、无效密钥、权限或 IP 限制、余额不足、频率限制和网络失败六类结果，自动测试均能显示对应提示，错误分类通过率为 100%。
- **SC-003**: 只有音效配置、没有图片配置时，纯音效生成测试能够进入音效服务调用，图片配置错误数量为 0。
- **SC-004**: 用户主动生成测试音效后，在服务正常的情况下 30 秒内得到可播放结果或明确的超时说明，不出现无限转圈。
- **SC-005**: 测试音效完成或失败后，现有项目文件、素材清单和关卡数据的变化数量为 0。
- **SC-006**: 密钥出现在渲染状态、日志、错误信息、测试快照和用量记录中的次数为 0。
- **SC-007**: 现有桌面设置、Agent、项目创建、Phaser 编辑与试玩测试保持全部通过。

## Assumptions

- 用户当前使用 ElevenLabs 音效服务，本次实际试听入口先只支持 ElevenLabs。
- 基础检查继续作为无扣费检查；真正验证声音生成权限必须由用户主动点击测试音效。
- 测试音效采用固定、无语音、极短的游戏确认提示声，不能输入自定义提示词，以控制额度和测试范围。
- 临时测试音效只保留在当前设置窗口内；项目音效生成、选择、绑定与运行时播放属于后续功能。
- 用户已同意本次修改的范围，但真实测试音效所产生的第三方额度仍由用户在界面中逐次主动触发。
