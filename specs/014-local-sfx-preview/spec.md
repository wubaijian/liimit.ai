# Feature Specification: 本地游戏音效试听包

**Feature Branch**: `main`

**Created**: 2026-09-01

**Status**: Implemented

**Input**: 用户确认先由 Codex 在本机制作 6 个游戏音效，不调用 ElevenLabs 或其他外部音频 API，只提供试听，暂不接入游戏事件。

## User Story - 试听第一套离线音效

产品经理可以直接试听跳跃、金币、死亡、通关、击中敌人和检查点六个音效，判断整体卡通街机风格是否适合 liimit.ai 的 2D 横版游戏。

### Acceptance Scenarios

1. 六个音效均为可播放的标准 WAV 文件，彼此内容不同。
2. 生成过程不访问网络、不读取或使用任何 API Key，也不消耗第三方额度。
3. 每个声音有明确中文用途、时长和独立播放器。
4. 本阶段只生成试听文件，不修改任何现有游戏项目，也不绑定游戏动作。

## Requirements

- **FR-001**: 必须生成 `jump.wav`、`coin.wav`、`death.wav`、`level-clear.wav`、`enemy-hit.wav` 和 `checkpoint.wav`。
- **FR-002**: 所有文件必须为 44.1 kHz、16-bit、单声道 PCM WAV。
- **FR-003**: 音效必须由确定性的本地波形合成器生成，脚本不得包含网络请求或密钥读取。
- **FR-004**: 必须生成一个包含六个播放器和通俗说明的本地试听页。
- **FR-005**: 必须验证 WAV 头、时长、峰值、文件大小和内容唯一性。
- **FR-006**: 本阶段不得向用户游戏目录写入文件。

## Success Criteria

- **SC-001**: 六个 WAV 均能被浏览器或系统播放器识别。
- **SC-002**: 六个文件的内容哈希全部不同。
- **SC-003**: 不出现削波，归一化后的绝对峰值不超过 0.9。
- **SC-004**: 试听页可在本机直接打开，无需开发服务器或网络。

## Out of Scope

- 将音效绑定到跳跃、金币、死亡、通关等游戏事件。
- 在 liimit.ai 编辑器中增加音效素材库。
- 背景音乐、真人语音和写实环境声。
- 调用 ElevenLabs 或任何其他第三方音频生成服务。
