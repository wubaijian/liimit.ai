# Feature Specification: 横版试玩内置本地音效

**Feature Branch**: `main`

**Created**: 2026-09-01

**Status**: Implemented

**Input**: 用户确认第一套六个离线音效可以使用，进入第二部分，把它们接入固定 Phaser 横版游戏模板和当前演示项目。

## User Story - 试玩动作能听到对应声音

用户在 Web 试玩中跳跃、拾取金币、死亡、完成关卡、踩中敌人或激活检查点时，可以听到对应的已确认音效，不需要音频 API 和网络。

### Acceptance Scenarios

1. 新建的固定横版项目自动包含六个 WAV 文件，并在场景加载阶段完成加载。
2. 六类游戏动作分别只触发自己的声音。
3. 短时间内重复碰撞或重入不会造成同一声音无限叠加。
4. 浏览器尚未允许声音时，游戏继续运行，不因播放失败而中断。
5. 自动试玩无需声音也能继续运行；用户手动试玩后由浏览器正常解锁声音。
6. 当前 `星光森林` 演示项目保留已有美术和关卡，只增加声音文件与最小事件绑定。

## Requirements

- **FR-001**: 固定模板必须打包六个确认后的本地 WAV。
- **FR-002**: 场景必须在 `preload` 中加载六个固定声音键。
- **FR-003**: 跳跃、金币、死亡、通关、踩中敌人和检查点必须分别绑定正确声音。
- **FR-004**: 播放配置必须使用固定音量和最短重复间隔。
- **FR-005**: 声音锁定、缓存缺失或单次播放异常不得使游戏崩溃。
- **FR-006**: 不得调用 ElevenLabs 或其他外部音频 API。
- **FR-007**: 本阶段不得增加背景音乐、声音设置页或 AI 自动改音效功能。

## Success Criteria

- **SC-001**: 模板构建和当前演示项目构建均成功。
- **SC-002**: 自动契约验证六个文件、六次加载和六类事件绑定全部存在。
- **SC-003**: 现有桌面端、关卡编辑与试玩自动测试保持通过。
- **SC-004**: 当前演示项目页面可加载六个声音资源，不出现 404 或运行时异常。

## Out of Scope

- 用户在编辑器内更换、删除或调节音效。
- 背景音乐和总音量/静音开关。
- 向全部历史项目批量覆盖用户自定义代码。
