# Implementation Plan: 横版试玩声音控制

## Approach

扩展固定模板已有的游戏偏好设置，新增“音效是否开启”和“四档总音量”。继续使用原来的本机存储键，通过缺省值兼容旧数据。游戏设置页增加两个简单按钮；统一声音播放入口在播放前检查开关，并把单个音效的安全音量乘以总音量。

当前 `星光森林` 采用同样的小范围补丁，只同步偏好设置、设置菜单和播放判断，不覆盖森林美术与关卡。

## Constitution Check - Before Design

- 本功能只读取浏览器本机存储，不新增 Renderer、IPC、凭据、网络或文件系统边界。
- 新字段具备旧数据兼容读取和默认值测试，符合兼容性要求。
- 声音播放失败仍不得影响游戏运行。
- 用户可见文案继续使用现有游戏内设置，不引入历史品牌。

## Design Decisions

- 默认音效开启、默认总音量 100%，保持升级前行为。
- 音量使用 25%、50%、75%、100% 四档循环，适合 Phaser 文字按钮和键鼠操作。
- 总音量只缩放现有每个音效的安全音量，不绕过原有防重复规则。
- 继续使用 `liimit.ai:platformer-preferences:v1`，旧 JSON 缺少字段时补默认值，不强制迁移或清空用户数据。

## Constitution Check - After Design

- 已包含旧数据读取、非法值回退和持久化测试。
- 没有扩大外部副作用和安全权限。
- 模板和当前演示项目均需要独立构建验证，桌面端需要完整回归。

## Validation

- 游戏偏好纯逻辑测试：默认值、旧数据、非法数据、保存和音量循环。
- 模板源码契约：两个设置入口、静音判断、总音量缩放。
- 固定模板 smoke/typecheck/test/build。
- 当前 `星光森林` typecheck/test/build。
- 桌面端完整 typecheck/test/build。
- 应用内 Web 试玩手动确认设置页面和持久化。
