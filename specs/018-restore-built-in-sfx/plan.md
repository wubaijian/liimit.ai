# Implementation Plan: 一键恢复内置音效

## Approach

扩展已有项目音效覆盖服务，增加只读状态检查和单项恢复。状态检查只返回六个布尔值；恢复把对应 JSON 字段改为 `null` 后调用现有构建能力，失败则写回旧配置。自定义 MP3 不删除。

设置界面在进入 AUDIO、切换项目、应用成功和恢复成功后刷新状态，并在用途选择旁显示当前来源。恢复按钮只在当前声音确有覆盖时启用。

## Constitution Check

- Renderer 不读取项目文件、不传路径；所有读写仍在 Main 服务内完成。
- 用户确认后才产生项目写入和构建副作用。
- 不删除文件，失败可回滚，旧项目空配置安全显示为内置。
- 新 IPC 有强类型契约、运行时校验和聚焦测试。

## Validation

- 服务状态、成功恢复、无覆盖和构建失败回滚测试。
- IPC 确认、强类型和无路径契约测试。
- UI 状态与按钮契约测试。
- 模板 smoke、`星光森林` 与桌面端完整回归。
- 应用内实际查看“内置音效”状态，不修改用户项目。
