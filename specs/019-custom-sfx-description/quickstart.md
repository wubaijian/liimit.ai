# Quickstart: 自定义音效描述

## 不调用 API 的自动检查

1. 运行音效服务测试，使用本地假响应验证中文、英文、去空格和无效描述。
2. 运行桌面契约测试，确认 Renderer 只传用途和描述，Main 再次校验，记录不保存描述。
3. 运行桌面端类型检查、完整测试和正式构建。

预期：所有检查通过，网络调用由假响应替代，不消耗 ElevenLabs 额度。

## 界面检查

1. 打开设置并进入 AUDIO / ElevenLabs。
2. 确认声音用途下方出现“描述你想要的声音”输入框、用途示例和 `0/300` 字数。
3. 不输入内容时，生成按钮不可用并显示提示。
4. 输入中文或英文，确认字数变化且按钮恢复可用。
5. 切换声音用途，确认示例变化但已输入文字不被覆盖。

界面检查不点击生成按钮，不调用 API。

## 后续可选真实验收

只有用户明确允许消耗额度时，才用一条中文描述进行真实生成、试听和应用测试；本功能交付不把该付费检查冒充已执行。
