# Feature Specification: 自定义音效描述

**Feature Branch**: `main`

**Created**: 2026-09-02

**Status**: Implemented

**Input**: 按 V3.1 音效增补需求逐步补齐能力；本步骤只让用户用中文或英文描述想要的音效，并保留现有单条生成、试听、确认应用和恢复流程。

## User Scenarios & Testing

### User Story 1 - 用户描述自己想要的声音 (Priority: P1)

游戏制作人员在 AI 音效区域选择声音用途后，可以输入一句中文或英文描述，再生成与描述相符的一条临时试听音效。用户无需理解提示词写法，界面会给出容易照着写的示例。

**Why this priority**: 这是从固定预设走向 PRD 所描述“用户说出想要的声音”的第一步，也是后续三候选、重新生成和生成记录的共同输入。

**Independent Test**: 选择“拾取金币”，输入“短促、明亮、像玻璃轻碰的奖励声”，点击生成；请求使用该描述，返回一条可以试听的音效，游戏在用户确认前不发生变化。

**Acceptance Scenarios**:

1. **Given** 用户已经保存可用的音效服务，**When** 输入一段中文描述并点击生成，**Then** 系统使用这段描述生成当前所选用途的一条临时音效。
2. **Given** 用户希望使用英文描述，**When** 输入有效英文并点击生成，**Then** 系统允许发起生成，不要求改成中文。
3. **Given** 描述只有空格或没有内容，**When** 用户尝试生成，**Then** 系统不调用外部服务，并用普通语言提示“请先描述你想要的声音”。
4. **Given** 用户切换声音用途，**When** 查看描述区域，**Then** 界面展示与新用途匹配的示例，但不会用示例内容覆盖用户已经输入的文字。
5. **Given** 用户生成了一条临时音效，**When** 尚未点击“应用到当前游戏”，**Then** 当前游戏文件和已绑定音效保持不变。

### Edge Cases

- 描述首尾包含空格时，生成前去掉首尾空格。
- 描述超过 300 个字符时，界面不允许继续输入或提交超过限制的内容，并显示剩余字数。
- 描述包含不可见控制字符时，系统拒绝生成并提示重新输入；正常中文、英文、数字和常用标点允许使用。
- 用户在生成期间不能重复提交第二个请求；当前应用仍保持单次只能生成一条。
- API 失败或超时时保留用户输入，用户可以修改后再次生成。

## Requirements

### Functional Requirements

- **FR-001**: 系统必须在现有 AI 音效区域提供自由描述输入框。
- **FR-002**: 系统必须接受中文或英文描述，去除首尾空格后长度必须为 1～300 个字符。
- **FR-003**: 系统必须为六种现有声音用途分别提供简单示例，示例只用于帮助理解，不得自动作为用户输入提交。
- **FR-004**: 描述为空或无效时，系统必须阻止外部调用并显示普通语言提示。
- **FR-005**: 生成请求必须同时包含受支持的声音用途和经过校验的用户描述；界面不得提交 API Key、接口地址或目标文件路径。
- **FR-006**: 可信端必须再次校验描述长度和不可见控制字符，不能只依赖界面校验。
- **FR-007**: 外部调用记录不得保存用户描述，现有密钥保护规则保持不变。
- **FR-008**: 生成失败、超时或用户关闭设置窗口时，不得写入当前游戏；只有用户确认应用后才能继续使用现有项目音效替换流程。
- **FR-009**: 本步骤继续只生成一条约 0.5 秒的候选音效；三候选、时长选择、主动取消和关卡编辑器入口不在本步骤内。

### Key Entities

- **音效生成描述**: 用户为当前声音用途输入的一段临时文字；包含去除首尾空格后的正文，不持久化到调用记录或游戏项目。
- **声音用途**: 当前已经支持的跳跃、拾取金币、角色死亡、关卡完成、敌人被消灭和检查点六种固定选项。
- **临时试听音效**: 根据声音用途和用户描述生成的一条临时结果；用户确认前只存在于当前设置窗口。

## Assumptions

- 继续使用现有已经配置的 ElevenLabs 音效服务和现有 30 秒超时、1 MiB 大小保护。
- 本步骤不改变当前项目音效文件格式、应用确认、重新构建和恢复内置音效机制。
- 描述输入框初始为空，示例通过占位说明展示，避免用户误以为系统已自动填写。

## Out of Scope

- 一次生成三个候选音效及候选对比。
- 0.5～8 秒时长选择。
- 等待计时、主动取消、部分成功和补充生成。
- 新增二段跳、受伤、开门或机关等声音用途。
- 把音效入口移动到关卡编辑器。
- 保存描述、费用、候选选择或试玩保留结果等完整生成记录。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 用户可以在 30 秒内完成“选择用途、输入描述、发起生成”三个操作，不需要查看帮助文档。
- **SC-002**: 中文和英文各至少一个有效描述能够通过输入与安全校验进入现有音效生成流程。
- **SC-003**: 空描述、超长描述和含不可见控制字符的描述共三类无效输入，外部调用次数均为 0。
- **SC-004**: 用户描述不会出现在本机 API 调用记录、错误记录或项目文件中。
- **SC-005**: 现有试听、确认应用、恢复内置音效以及其他五种声音用途保持可用，相关自动检查全部通过。
