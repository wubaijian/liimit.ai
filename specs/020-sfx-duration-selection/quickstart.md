# Quickstart: 音效时长选择

## 自动检查（不调用 API）

1. 用本地假响应验证 0.5、3.5 和 8 秒原样进入请求并返回。
2. 验证 0、8.5、0.7、非数字在网络前被拒绝。
3. 验证六种用途推荐值和界面选择框契约。
4. 运行桌面端类型检查、完整测试和正式构建。

## 界面检查（不点击生成）

1. 打开设置 → AUDIO。
2. 确认跳跃显示“0.5 秒（推荐）”。
3. 输入一段临时描述，把时长改成 3.5 秒，确认旧试听区域不会出现且按钮状态正常。
4. 切换到完成关卡，确认时长变成“2 秒（推荐）”，描述仍保留。
5. 清空临时描述，恢复跳跃用途。

全程不点击生成，不使用 ElevenLabs 额度，不修改游戏项目。
