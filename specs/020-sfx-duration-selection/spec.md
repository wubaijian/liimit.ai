# Feature Specification: 音效时长选择

**Feature Branch**: `main`

**Created**: 2026-09-02

**Status**: Implemented

**Input**: 在已经完成的自定义音效描述基础上，让用户选择 0.5～8 秒的生成时长，并为不同声音用途提供推荐时长；本步骤仍只生成一条候选音效。

## User Scenarios & Testing

### User Story 1 - 用户选择音效持续时间 (Priority: P1)

游戏制作人员选择声音用途并填写描述后，可以在生成前选择声音持续多久。界面默认提供适合当前用途的推荐时长，用户也可以改成 0.5～8 秒内的其他时长。

**Why this priority**: 不同声音用途需要的长度明显不同。跳跃和金币通常很短，通关提示可以更长；让用户在生成前选择可以减少重复生成。

**Independent Test**: 选择“完成关卡”时看到推荐 2 秒，把时长改成 3.5 秒后发起本地假请求；请求使用 3.5 秒，返回试听信息也显示 3.5 秒。

**Acceptance Scenarios**:

1. **Given** 用户打开音效生成区域，**When** 当前用途为跳跃，**Then** 时长默认显示 0.5 秒并标注为推荐值。
2. **Given** 用户选择完成关卡，**When** 用途发生变化，**Then** 时长更新为该用途推荐的 2 秒。
3. **Given** 用户在 0.5～8 秒范围内选择一个半秒档位，**When** 点击生成，**Then** 外部生成请求使用所选时长。
4. **Given** 用户选择 3.5 秒并成功生成，**When** 查看临时试听，**Then** 页面显示这条试听使用 3.5 秒生成。
5. **Given** 时长数据被篡改为范围外、非数字或非半秒档位，**When** 请求到达可信端，**Then** 系统拒绝请求且不调用外部服务。
6. **Given** 用户修改时长，**When** 之前已经有一条临时试听，**Then** 旧试听被清除，避免用户把旧时长结果误认为新结果。

### Edge Cases

- 最小值为 0.5 秒，最大值为 8 秒，包含两端。
- 可选档位按 0.5 秒递增，共 16 个值。
- 切换声音用途时恢复该用途的推荐时长，不保留上一个用途的选择。
- API 失败或超时时保留当前用途、描述和时长，用户可以直接重试。
- 时长只用于临时生成和试听，不写入项目配置；应用到游戏后由音频文件本身决定实际长度。

## Requirements

### Functional Requirements

- **FR-001**: 系统必须在音效描述区域附近提供 0.5～8 秒的时长选择。
- **FR-002**: 可选时长必须按 0.5 秒递增，并显示“秒”单位。
- **FR-003**: 六种现有声音用途必须分别配置推荐时长：跳跃 0.5 秒、金币 0.5 秒、角色死亡 1 秒、完成关卡 2 秒、踩中敌人 0.5 秒、检查点 1 秒。
- **FR-004**: 切换声音用途时，时长必须更新为新用途的推荐值；描述文字不得因此被覆盖。
- **FR-005**: 生成请求必须同时包含固定用途、有效描述和有效时长；界面不得提交凭据、接口地址或路径。
- **FR-006**: 可信端必须再次检查时长为有限数字、位于 0.5～8 秒且符合半秒档位。
- **FR-007**: 音效服务必须把经过校验的时长用于生成请求，并在临时试听结果中返回该时长。
- **FR-008**: 修改时长必须清除旧的临时试听，但不得修改当前游戏或已应用音效。
- **FR-009**: 本步骤继续只生成一条候选；三候选、生成取消、部分成功和费用统计不在本步骤内。

### Key Entities

- **音效时长选择**: 当前设置窗口中的临时数值，取 0.5～8 秒之间的半秒档位。
- **推荐时长**: 根据六种固定声音用途映射出的初始值。
- **临时试听音效**: 增加生成时长信息的一条试听结果；用户确认前不写项目。

## Assumptions

- ElevenLabs 当前音效端点支持本步骤的 0.5～8 秒范围。
- 继续沿用 30 秒超时、1 MiB 大小限制和一次只生成一个请求的保护。
- 不保存用户上次选择的时长；每次打开设置从当前用途推荐值开始。

## Out of Scope

- 一次生成三个候选音效。
- 自由输入任意小数或超过 8 秒的音效。
- 根据描述由 AI 自动判断时长。
- 保存时长到项目设置或生成历史。
- 修改已应用音频的播放速度或裁剪文件。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 用户可以在一次点击内从 16 个明确档位中选择 0.5～8 秒的时长。
- **SC-002**: 六种用途的推荐值与 FR-003 完全一致，切换用途后在 1 秒内显示新推荐值。
- **SC-003**: 0.5、3.5 和 8 秒三个代表值能够进入本地假生成流程，并原样返回到试听信息。
- **SC-004**: 0、8.5、非数字和 0.7 秒四类无效输入均在外部调用前被拒绝。
- **SC-005**: 现有描述、试听、应用和恢复能力保持可用，桌面端完整自动检查全部通过。
