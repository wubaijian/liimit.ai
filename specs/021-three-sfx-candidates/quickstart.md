# Quickstart: 三候选音效试听与选择

## 自动检查（不调用真实 API）

1. 用三个本地成功响应验证候选编号为 1、2、3，结果顺序稳定且固定尝试 3 次。
2. 用一个和两个失败响应验证成功候选被保留、失败数量准确且不补发。
3. 用三个失败响应验证批次整体报错且没有可应用候选。
4. 验证重叠批次被可信端阻止，用量记录为 3 次调用且不记录敏感内容。
5. 验证 Renderer 建立三个临时播放地址、只允许单选、未选不应用、选择后只应用所选字节。
6. 运行桌面端两个 TypeScript 检查、完整测试、正式构建和 `git diff --check`。

## 真实界面检查（不点击生成）

1. 打开设置 → AUDIO，确认说明和按钮明确写出“一次生成 3 条”以及额度约为单条的 3 倍。
2. 输入临时描述并选择时长，确认生成按钮可用，但不要点击。
3. 通过本地假批次界面或组件测试确认三张候选卡、单选状态和部分失败提示。
4. 清空临时输入并关闭设置。

真实界面检查不得点击生成，不消耗 ElevenLabs 额度，不修改游戏项目。
