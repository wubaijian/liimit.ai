# Quickstart: 音效生成进度与主动停止

## 自动检查（不调用真实 API）

1. 用三个可控制的本地假请求验证开始为 0/3，随后准确更新为 1/3、2/3、3/3。
2. 验证每次都满足“已完成 = 成功 + 失败”，部分失败仍归入失败数量。
3. 点击停止后验证三个未完成请求均收到停止信号，批次以取消结束。
4. 验证一条成功后停止仍整批作废，不返回成功候选。
5. 验证 Main 只控制当前唯一批次，空闲停止安全，进度和停止数据无敏感字段。
6. 验证 Renderer 点击停止后立即禁用按钮，并丢弃与完成同时到达的迟到结果。
7. 运行桌面端两个 TypeScript 检查、完整测试、正式构建和 `git diff --check`。

## 真实界面检查（不点击生成）

1. 打开设置 → AUDIO，确认音效生成说明包含进度、主动停止和额度提示。
2. 输入临时描述并选择时长，确认表单与生成入口正常，但不要点击生成。
3. 进度变化和停止状态由本地假请求自动测试验证，不触发 ElevenLabs。
4. 清空临时输入并关闭设置。

真实界面检查不得点击生成，不消耗 ElevenLabs 额度，不修改游戏项目。
