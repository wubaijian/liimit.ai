# 《火山逃生》3 关固定骨架

## 第 1 关：岩浆边缘

- 目的：让玩家学会移动、跳跃、收集和到达终点。
- 物体：普通平台、1 段岩浆坑、5 个火焰晶币、1 个检查点、1 个终点。
- 能力：普通跳跃，不开二连跳。
- 难度：低，只要向右前进即可完成。

## 第 2 关：熔炉桥梁

- 目的：学会利用移动平台和二连跳。
- 物体：普通平台、2 个移动平台、2 段岩浆坑、尖刺、6 个火焰晶币、1 只史莱姆、1 个检查点、1 个终点。
- 能力：开启二连跳。
- 难度：中，需要观察平台移动节奏。

## 第 3 关：火山核心

- 目的：组合前两关能力，完成最终逃生。
- 物体：高低平台、3 个水平或垂直移动平台、连续岩浆坑、尖刺、8 个火焰晶币、2 只史莱姆、1 只蜜蜂、2 个检查点、1 个终点。
- 能力：开启二连跳，移动速度略高。
- 难度：高，但不增加新的底层玩法。

## 原创视觉元素

- 主角：戴石壳头盔的白色小熊探险者。
- 平台：深蓝黑色火山岩，边缘带柔和黄色矿晶，不使用原项目的土黄色岩块造型。
- 岩浆：珊瑚红与金黄色流体，视觉上明确是死亡区域。
- 收集物：漂浮的六边形火焰晶币。
- 检查点：矮小的金色光柱石碑。
- 终点：发光的冰蓝色山洞出口，不使用白旗。
- 背景：暗紫色火山洞、多层远景与热气薄雾，不复制原项目的火山构图。
