# Feature Specification: 原创火山跳跃固定游戏

## 目标

在现有 Phaser 3 横版跳跃模板上制作一款原创火山主题固定示例游戏。保留 Limit AI 现有的拖动编辑、保存、Web 试玩、多关卡和音效能力，不引入 Godot 或 Phaser Editor。

## 产品范围

- 只增加一款固定游戏：《火山逃生》。
- 首版包含 3 个固定关卡。
- 使用原创卡通火山美术，不复制 `editor-example-volcano` 的付费素材。
- 玩法只使用现有对象：普通平台、移动平台、坑洞/岩浆、尖刺、收集物、检查点、终点、史莱姆和蜜蜂。
- 支持键盘操作和二连跳。

## 本轮边界

本轮只完成原创美术方向图和迁移拆分，不替换现有模板、不改动用户项目、不调用用户已配置的模型 API。

## 验收标准

1. 美术方向图与原付费素材在角色、平台造型、背景和色彩组织上明显不同。
2. 方向图能清楚表达横版跳跃、岩浆危险、收集物和终点。
3. 形成 3 关固定关卡的难度递增说明。
4. 用户确认美术方向前不将它写入游戏模板。
