# 零号工厂逃生：正式内置游戏说明

## 产品定位

《零号工厂逃生》是 liimit.ai 的第二个正式内置示例。它继续使用 Phaser 3、2D 横版平台跳跃和应用内 Web 试玩，但把核心体验从追逐逃生改为轻量机关解谜。

## 玩家目标

玩家需要操纵主角穿过失控的机械工厂，取得门卡、启动开关、关闭激光门，最终到达中央控制室出口。

## 三关结构

1. 流水线车间：学习机械移动平台，躲避齿轮和基础巡逻机器人。
2. 门禁区域：先取得蓝色门卡，再打开对应的安全门。
3. 中央控制室：启动两个开关，关闭最终激光门并到达出口。

## 第一版规则

- 使用键盘移动、跳跃和二连跳。
- 门卡与安全门一一对应。
- 指定开关全部启动后，激光门关闭。
- 碰到激光或机器人会死亡。
- 关卡仍可保存、复制、编辑和指定起点试玩。
- 继续使用本机保存和手动导出。

## 本轮边界

- 只制作固定的三关游戏。
- 不增加射击、背包或复杂战斗系统。
- 不调用用户配置的 AI API。
- 美术全部使用原创本地素材。
