# Feature Specification: 紧凑进度与大尺寸 AI 助手

Created: 2026-09-17
Status: Approved by implementation request
Input: 压缩制作进度，扩大 AI 助手，减少滚动。

## User Scenarios & Testing

### US1 — 一眼看到进度（P1）

打开游戏后，简短状态与横排三阶段替代大说明卡。独立验收：进度区默认字号不超过110像素高，状态不伪造完成。

### US2 — 方便持续使用 AI（P1）

进入项目即可看到助手；100条历史时输入和发送/停止仍可见。验收：历史独立滚动，确认/调整/取消保留，切换项目显示对应记录。

### Edge Cases

长方案、无历史、生成中、准备失败、小窗口、阅读历史时新输出到达。

## Requirements

- FR-001: 简化进度，保留状态及三个阶段。
- FR-002: 扩大助手宽高，默认可见。
- FR-003: 输入区固定底部；历史和方案在独立滚动区。
- FR-004: 简介默认折叠；阅读历史时不强制跳底，提供回到最新按钮。
- FR-005: 不改变执行、计费、停止和确认权限，不删除用户数据。

## Success Criteria

- SC-001: 1440×900窗口进度不超过110像素高，助手至少400像素宽。
- SC-002: 100条历史时输入与发送/停止按钮无需滚动即可使用。
- SC-003: 1100×760窗口保留独立记录区和输入框，更窄时所有操作仍可到达。

## Assumptions

保持白色黄色风格，不增加API调用，不重做关卡编辑器。
