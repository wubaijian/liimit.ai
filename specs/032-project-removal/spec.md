# Feature Specification: 项目移除与废纸篓

**Created**: 2026-09-17
**Status**: Approved
**Input**: 用户确认增加项目菜单、列表移除、文件移到废纸篓、操作前确认。

## User Scenarios & Testing

### US1 — 清理列表（P1）

项目菜单选择从列表移除，确认后记录消失，文件原样保留。取消无变化；重启不再出现；移除当前项目返回首页，其他项目不受影响。

### US2 — 清理文件（P1）

确认名称与路径后将整个项目目录移到废纸篓，再移除记录。文件移动失败保留记录；记录保存失败明确提示文件已移动及恢复方法。

### Edge Cases

活动任务、并发读写、重复点击、无效ID/方式、目录不存在、符号链接、共享/嵌套项目、身份不符、存储失败。

## Requirements

- FR-001：可访问的项目菜单提供两种方式；原生确认框显示名称路径，默认取消。
- FR-002：列表移除不改文件，记录持久化，其他项目与配置不受影响。
- FR-003：文件只进废纸篓；核验独立项目目录身份，拒绝重要目录、符号链接和重叠项目。
- FR-004：阻止与生成、准备、读写并发和重复操作；执行结束释放锁，停止目标预览。
- FR-005：成功更新列表和选择；失败/取消不误报，移动成功但存储失败给恢复提示。
- FR-006：只用临时项目验证，不删除用户项目，不调用用户 API。

## Key Entities

请求：项目ID、移除方式；结果：取消/已移除、文件是否移到废纸篓。旧记录格式不变。

## Success Criteria

- SC-001：三次操作内打开确认框，取消无副作用。
- SC-002：成功与失败路径有自动测试，其他项目文件及配置不变。
- SC-003：活动任务及不安全目标被拦截，只对临时测试项目验证移动。

## Assumptions

不做批量删除，不清空应用历史/费用记录；从废纸篓恢复文件不等于恢复列表记录。不替用户删除旧项目。
