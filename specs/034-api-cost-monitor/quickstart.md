# 零付费验收与用户操作

1. 运行desktop typecheck/test/build，假HTTP服务仅监听127.0.0.1。
2. 验证SSE分包、费用未知、3错、次数、并发预算、80%提醒、拒绝重复素材、重定向不泄密、取消和重启。
3. 打开已安装应用，进入已有项目，AI助手上方应有费用条。
4. 打开“费用与预算”，核对默认预算未启用、价格空、调用上限20；关闭不能启动生成。
5. 设置→API管理中也可查看音效试听账本，未生成时“暂无调用”。
6. 用户提供实际价格后填写，保存只对下次任务生效。不为演示保存虚构价格，不为验证点击付费生成。
7. API具体兼容性和账单精度需后续用户授权的真实小额测试；本次不执行。
