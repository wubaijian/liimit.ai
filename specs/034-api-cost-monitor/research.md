# Research

- 已有 apiUsageStore 在最终 Runtime result 才汇总，不能覆盖暂停或逐请求阻断。新账本独立存储避免把不完整历史伪装成完整收费记录。
- 本机固定路由网关观察内置主模型、推理与素材 HTTP 调用；随机令牌通过既有 FD 传递，加入 Agent 脱敏列表，不写配置文件。
- 主模型兼容API返回 usage；SSE可能分包，按最终累计值替换而非重复相加。未知或独立缓存写入计价无法解释则金额未知。
- 价格来自用户实际服务商，不从模型名猜测；人民币单币种。音效试听使用 eleven_text_to_sound_v2，与音乐模型分别填价。
- 请求串行使预算检查和结算之间没有第二笔在途；但第一笔的实际费用不可提前精确知道，不承诺绝对不超支。
- 现有连续工具错误停止机制保留；新网络错误停止与20次默认上限独立生效。
- 不包含MCP、脚本直连、服务商账户全局账单、连接测试；不追溯历史扣费。
